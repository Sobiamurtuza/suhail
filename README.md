# Muhammad Suhail — Portfolio

A responsive academic/AI portfolio designed for GitHub Pages.

## Files
- `index.html` — portfolio content
- `style.css` — royal-blue visual design
- `script.js` — mobile navigation, scroll reveal, active section
- `assets/suhail-profile.jpg` — uploaded profile photo
- `assets/Muhammad-Suhail-CV.pdf` — uploaded CV

## GitHub Pages
1. Create a GitHub repository.
2. Upload all files/folders while preserving the `assets` folder.
3. In GitHub: Settings → Pages → deploy from the `main` branch.
4. Open the generated Pages URL.

## Personal links
In `index.html`, replace the generic LinkedIn and GitHub links in the Contact section with your actual profile URLs.

## Public privacy
The CV contains personal information that is better kept off a public portfolio. This site intentionally does not publish passport number, date of birth, home address, WhatsApp number, or referee contact details.
